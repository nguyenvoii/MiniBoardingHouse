# Demo UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trang web tinh (chi tren may Phi) de bam thu cac API quan ly tai khoan voi SQL that.

**Architecture:** HTML + JS thuan trong `demo-ui/` (gitignored), Spring Boot phuc vu qua `spring.web.resources.static-locations` dat trong `application-local.properties`; phan duy nhat vao repo la cho phep `/ui/**` trong `SecurityConfig`.

**Tech Stack:** Spring Boot 3.3.5, HTML/CSS/JavaScript thuan (fetch), Node chi de `node --check`.

**Spec:** `docs/superpowers/specs/2026-11-14-demo-ui-design.md`

## Global Constraints

- `demo-ui/` KHONG commit; chi `SecurityConfig` + test + docs vao git. Khong them thu vien/build tool.
- Du lieu tu API dua vao trang bang `textContent`/`createElement`, khong `innerHTML` voi du lieu dong.
- Tieng Viet co dau trong giao dien; tep UTF-8. Lenh Maven nhu cac ke hoach truoc. Khong them dong Co-Authored-By. Khong push.

## Review Focus

1. Khi bat bao mat, truy cap `/ui/**` khong token khong bi 401; moi duong dan API khac van bi 401 (Task 1).
2. Dang nhap sai/het han: giao dien khong treo, hien thong bao, quay ve dang nhap (Task 2).
3. Mat khau tam chi hien 1 lan va khong luu vao sessionStorage (Task 2).
4. Nguoi thue khong thay muc nhan vien/nhat ky he thong (Task 2).

### Task 1: Cho phep cong khai /ui/**

**Files:** Modify `shared/config/SecurityConfig.java`, `src/test/java/.../shared/config/SecurityRulesTest.java`

- [ ] **Step 1: Test** `staticUiIsPublicButApiIsNot`: khong token, `GET /ui/index.html` -> `isNotFound()` (khong co file trong test, quan trong la KHONG 401); `GET /api/probe/staff` van `isUnauthorized()`.
- [ ] **Step 2: Chay** `"$MVN" test -Dtest=SecurityRulesTest` -> FAIL (hien tra 401 cho /ui/**).
- [ ] **Step 3: Implement** them `"/ui/**"` vao `permitAll()` trong `SecurityConfig` (chi trong nhanh `enabled`), cap nhat Javadoc.
- [ ] **Step 4: Chay** `"$MVN" test` -> PASS. **Commit.**

### Task 2: Giao dien

**Files:** Create `demo-ui/index.html`, `demo-ui/style.css`, `demo-ui/app.js`; Modify `.gitignore` (them `demo-ui/`).

- [ ] **Step 1:** Viet 3 tep theo spec (dang nhap, menu theo vai tro, nhan vien, nhat ky he thong, nhat ky cua toi, ho so, doi mat khau, cap tai khoan nguoi thue, hop mat khau tam, xu ly 401).
- [ ] **Step 2: Kiem tra** `node --check demo-ui/app.js` -> khong loi; `grep -n "innerHTML" demo-ui/app.js` -> khong dong nao gan du lieu tu API.

### Task 3: Chay that tren SQL that

**Files:** `src/main/resources/application-local.properties` (gitignored; chi them dong).

- [ ] **Step 1:** Them `app.security.enabled=true`, `spring.web.resources.static-locations=file:./demo-ui/`, `spring.mvc.static-path-pattern=/ui/**` vao `application-local.properties` (giu nguyen cac dong cu).
- [ ] **Step 2:** Chay `mvn spring-boot:run` o cong 8080 (nen chay nen, giu chay); kiem tra bang curl: `GET /ui/index.html` 200 co `<title>`, `/ui/app.js` 200, `/api/staff` khong token 401, dang nhap admin 200.
- [ ] **Step 3:** Chay lai kich ban cac API ma giao dien goi (login, staff, status, logs) tren app dang chay de chac duong dan khop; ghi lai tai khoan thu tao ra (neu co).
- [ ] **Step 4:** Mo trinh duyet cho Phi (`start http://localhost:8080/ui/index.html`), bao cach tat app. **Commit** phan docs + SecurityConfig.
